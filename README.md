# das kefirt

Философский ресурс: https://das-kefirt.github.io/

Astro, статическая публикация на GitHub Pages, поиск Pagefind. Тексты — Markdown с отдельными полями примечаний и библиографии. Шрифты размещены на самом сайте; внешние шрифтовые сервисы не используются. Логотип сохранён без изменений.

## Редактор

1. Откройте https://app.pagescms.org/ и войдите под `das-kefirt`.
2. Разрешите Pages CMS доступ только к репозиторию `das-kefirt.github.io`.
3. Откройте репозиторий и ветку `main`. Конфигурация `.pages.yml` уже подготовлена.
4. В разделе «Публикации» создайте запись. Заполните заголовок, краткое описание, автора, раздел, дату и адрес латиницей.
5. Текст можно редактировать визуально или в режиме Source. Перед переносом сложного DOCX отдельно проверьте сноски, цитаты и курсив: импорт DOCX не реализован.
6. Чтобы выпустить материал, включите «Опубликовать на сайте» и сохраните. Дождитесь зелёного результата во вкладке GitHub Actions. Если сборка не прошла, предыдущая версия сайта продолжает работать.

Онлайн-вход и сохранение через Pages CMS требуют подключения редактора самим владельцем. До этого конфигурация проверена только локально, не через живой редактор.

## Отдельные примечания

В основном тексте вставьте `{{note:termin}}`. В поле «Примечания» добавьте запись с ID `termin`, видом примечания и его текстом. Не вводите номер вручную: сайт нумерует по порядку первого упоминания. Одинаковый ID можно упоминать многократно. ID разных примечаний внутри статьи должны отличаться. Кнопки «Вставить примечание» пока нет — используется текстовая метка. В режиме Source можно проверить, что метка не изменилась после визуального редактирования.

Библиография хранится отдельным списком. В описаниях можно использовать курсив и ссылки. Источник перевода — отдельное текстовое поле. Автор оригинала и переводчик указываются независимо.

## Черновики

`published: false` исключает текст из сайта, поиска, RSS, архива и карты сайта. Но репозиторий публичный: любой файл и его история доступны на GitHub. Конфиденциальные черновики следует хранить вне этого репозитория. Дата публикации — отображаемая дата, не планировщик.

## Структура

- `src/content/posts/*.md` — публикации. Имя файла определяет постоянный адрес `/read/имя-файла/`.
- `src/data/friends.json` — ресурсы друзей.
- `src/data/site.json` — описание и Telegram.
- `src/styles/global.css` — палитра, типографика, адаптивное оформление.
- `/preview/` — явно обозначенный образец оформления, закрытый от индексации (`noindex`) и исключённый из поиска, RSS и карты сайта. Он не является публикацией автора или проекта.

## Разработка

Node.js 24+. `npm ci`, затем `npm run dev`. Проверки: `npm test`, `npm run build`, `npm run verify`. Поиск создаётся при production-сборке, а не в dev-режиме. Коммит в `main` запускает публикацию GitHub Pages через `.github/workflows/deploy.yml`.

## Границы первой версии

Нет автоматического импорта Word, приватных редакционных черновиков, регистрации читателей и собственной базы комментариев. Обсуждение — ссылка на Telegram. Первые реальные тексты и ссылки друзей ещё не добавлены. Главная автоматически сменит вступительный блок на ленту после первой публикации.

Права на тексты и логотип принадлежат соответствующим правообладателям; публичная доступность репозитория сама по себе не предоставляет свободную лицензию на материалы.
