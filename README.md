# das kefirt

Философский ресурс: https://das-kefirt.github.io/

Astro, статическая публикация на GitHub Pages, поиск Pagefind. Тексты — Markdown с отдельными полями примечаний и библиографии. Шрифты размещены на самом сайте; внешние шрифтовые сервисы не используются. Логотип сохранён без изменений.

## Редактор на сайте

Откройте https://das-kefirt.github.io/editor/ (ссылка «Редактор» внизу сайта).

1. Нажмите «Загрузить Word / открыть файл» и выберите `.docx`. Обработка происходит в браузере, документ не отправляется на сторонний конвертер. Также можно начать новый текст.
2. Заполните автора, переводчика, название, описание, дату и раздел. Адрес предлагается по названию; его можно изменить до первой публикации.
3. Проверьте текст и примечания. Кнопка «+ Сноска» добавляет примечание в месте курсора. Жирный, курсив, заголовки, списки, цитаты и ссылки доступны на панели.
4. Откройте «Предпросмотр». Сохранение черновика в этом браузере автоматическое. Для резервной копии или другого компьютера нажмите «Скачать черновик» и затем откройте этот `.md` в редакторе.
5. Для отправки раскройте «Подключение GitHub». Под аккаунтом `das-kefirt` создайте fine-grained token для **Only select repositories → das-kefirt.github.io**, разрешение **Contents: Read and write**. Срок действия выбирает владелец. Вставьте ключ в поле на странице, затем нажмите «Опубликовать…», проверьте название и адрес и подтвердите.
6. Ключ используется только в текущей вкладке, не попадает в localStorage, скачанные файлы или GitHub-репозиторий. После перезагрузки его нужно вставить снова. Кнопка «Убрать ключ из вкладки» очищает поле. Сервисов авторизации, платного сервера и внешних CDN нет.
7. После отправки дождитесь успешной сборки в GitHub Actions. Редактор сообщает о сохранении файла, а не выдаёт его за уже развернутый сайт. При ошибке сборки продолжает работать предыдущая версия.

**Без ключа:** раскройте «Публикация без ключа», нажмите «Скачать для публикации», затем «Загрузить в GitHub». Перетащите файл `.md` и подтвердите Commit changes. Этот файл имеет `published: true`; обычный скачанный черновик — `false`.

**Правки:** «Открыть с сайта» загружает текущий файл и его SHA. Повторная публикация обновляет его только при совпадении версии; чужие изменения и случайная перезапись занятого адреса блокируются. Адрес уже опубликованного текста закреплён. При конфликте скачайте черновик, откройте актуальную версию и перенесите нужные правки. Скачанный из редактора черновик сохраняет исходную ревизию; при публичной отправке служебные сведения убираются.

Поддерживается один активный локальный черновик. Новый текст, открытие файла или статьи запрашивает подтверждение замены; для нескольких работ сохраняйте отдельные `.md` на компьютере. Очистка данных браузера удаляет локальный черновик. На чужом компьютере не сохраняйте чувствительные тексты.

**Импорт Word:** абзацы, заголовки, списки, выделения, ссылки, сноски и концевые сноски. Автоматически распознанный короткий заголовок выносится в поле названия; предисловие переводчика получает заголовок. Изображения оставляют видимую заглушку и предупреждение, а не загружаются молча. Формулы, сложные таблицы, рукописные номера сносок и исправления требуют проверки. Примите или отклоните исправления в Word до импорта. Лимит входного файла 10 МБ, обработка в отдельном worker с ограничением 45 секунд.

Страница редактора общедоступна, но без ключа с правами записи изменить репозиторий через неё нельзя. Она помечена noindex и исключена из Pagefind, RSS и sitemap. Локальные черновики не входят в сборку сайта.

### Дополнительно: Pages CMS

Конфигурация `.pages.yml` сохранена. При желании войдите на https://app.pagescms.org/ под `das-kefirt` и разрешите доступ только к этому репозиторию. Через Pages CMS также можно менять ресурсы друзей и настройки сайта. Живой вход и сохранение через этот внешний сервис владельцем ещё не проверены. Импорт Word реализован в собственном `/editor/`, а не в Pages CMS.

## Отдельные примечания

В основном тексте вставьте `{{note:termin}}`. В поле «Примечания» добавьте запись с ID `termin`, видом примечания и его текстом. Не вводите номер вручную: сайт нумерует по порядку первого упоминания. Одинаковый ID можно упоминать многократно. ID разных примечаний внутри статьи должны отличаться. В собственном редакторе кнопка «+ Сноска» ставит эту метку автоматически. При работе через Pages CMS в режиме Source можно проверить, что метка не изменилась после визуального редактирования.

Библиография хранится отдельным списком. В описаниях можно использовать курсив и ссылки. Источник перевода — отдельное текстовое поле. Автор оригинала и переводчик указываются независимо.

## Черновики

`published: false` исключает текст из сайта, поиска, RSS, архива и карты сайта. Но репозиторий публичный: любой файл и его история доступны на GitHub. Конфиденциальные черновики следует хранить вне этого репозитория. Дата публикации — отображаемая дата, не планировщик.

## Структура

- `src/content/posts/*.md` — публикации. Имя файла определяет постоянный адрес `/read/имя-файла/`.
- `src/data/friends.json` — ресурсы друзей.
- `src/data/site.json` — описание и Telegram.
- `src/styles/global.css` — палитра, типографика, адаптивное оформление.
- `/preview/` — явно обозначенный образец оформления, закрытый от индексации (`noindex`) и исключённый из поиска, RSS и карты сайта. Он не является публикацией автора или проекта.

## Разработка

Node.js 24+. `npm ci`, затем `npm run dev`. Проверки: `npm test`, `npm run build`, `npm run verify`. Поиск создаётся при production-сборке, а не в dev-режиме. Коммит в `main` запускает публикацию GitHub Pages через `.github/workflows/deploy.yml`.

## Границы первой версии

Нет синхронизации приватных черновиков между устройствами, регистрации читателей и собственной базы комментариев. Черновики собственного редактора хранятся локально в браузере или в скачанных файлах. Обсуждение — ссылка на Telegram. Первые реальные тексты и ссылки друзей ещё не добавлены. Главная автоматически сменит вступительный блок на ленту после первой публикации.

Права на тексты и логотип принадлежат соответствующим правообладателям; публичная доступность репозитория сама по себе не предоставляет свободную лицензию на материалы.
