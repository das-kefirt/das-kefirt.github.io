# Обложки

Загружайте сюда только подготовленные редактором `.webp`, сохраняя имя файла.
Оригиналы PNG, JPEG и SVG храните отдельно от репозитория.

Редактор именует обложки по SHA-256 содержимого: один подготовленный файл можно использовать в нескольких статьях без дубликатов.
Сборка публикует только используемые обложки. Git сохраняет предыдущие версии в истории репозитория.
